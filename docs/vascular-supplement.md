## 几何依据与配准方法

固定来源是 Z-Anatomy `6c7f9016bd5899ac8edafd31b9900c151df42ed6` 的 `Resources/Models/FBX/CardioVascular41.fbx`：

- Git blob：`aa5bbcb63ae6e9ace8051111b3a85ea87f00c4f3`。
- SHA-256：`ed7d049117cc944a8c47a416b16ade642cbd1392bbcce3c677450d3234dbf680`。
- 源文件为 64,889,388 字节；只提取选定的、有真实三角形的解剖网格，不将标签或空标记作为血管。
- 来源、许可、源网格名与 ID、配准记录逐项保存在发布清单中。来源及再分发许可见 [ATTRIBUTION.md](../public/ATTRIBUTION.md)。

FBX 世界坐标从厘米转换为米。头部使用已有的颅骨配准矩阵，并在颈部以连续权重过渡到躯干坐标。重要主干的旧顶点和三角形全部保留；新源片段在旧端附近截取横断面、匹配中心及截面尺寸，以约 6 mm 重叠区接入。调整在约 20 mm 范围内平滑衰减。

椎动脉、颈外静脉的源入口定位到原锁骨下血管截面内部；乙状窦的源出口在 30 mm 范围内适配颈内静脉上端。端部平移限制在 20 mm 以内。没有用任意生成的曲线代替缺失的血管路径。

**这些接合使用重叠表面，不是密闭连续的血管腔。** 不能用于血流模拟。原端帽和局部表面可能仍在交叠区域内部；配准以及与骨骼、神经、肌肉的全部空间关系未经过专业解剖审校。

## 验证结果与界限

[检查清单](../scripts/vascular-requirements.json)包含 110 项重要血管名称，其中 107 项有网格，另 3 项的缺失原因见上表。95 组纳入验收的连接均通过“最近顶点距离不超过 5 mm”的大缺口筛查；已知未补齐的腰升静脉连接单独测量并明确报告。

原先约 62.5～63.4 mm 的颈动脉缺口和约 50.2～50.9 mm 的椎动脉缺口，补充后相应网格的最近顶点距离均小于 1 mm。8 处旧网格与源片段接合的最近顶点距离约 0.18～0.44 mm。该指标只用于筛查几何大缺口，**不证明血管腔连续或解剖正确**。

- 验证原主干的顶点和索引前缀逐字节保留，原有分支接口不因截短替换而丢失。
- 验证全部缓冲区、索引、包围盒、gzip 一致性及补充文件哈希。
- 检查来源三角形变形后的方向和面积；本次检查未发现法线方向翻转。最小面积比约 0.13，最大约 3.24，较大变化发生在局部接合区域，仍需专业审校。
- 浏览器测试覆盖桌面端血管分组搜索、隔离、缺失说明，以及移动端椎动脉选择；实际截图用于检查显示。

详细机器可读结果：[覆盖与距离](vascular-coverage.json)、[配准与三角形检查](vascular-registration.json)。

## 重建

需要 Node 依赖和含 NumPy/SciPy 的 Python 环境，版本见 `scripts/registration-requirements.txt`。先构建基础模型和肌肉/关节补丁，再构建本血管补丁：

```sh
python3 scripts/fetch-supplemental-sources.py --vascular --workers 4
node scripts/prepare-vascular.mjs
work/registration-env/bin/python scripts/register-vascular.py
node scripts/build-vascular-atlas.mjs
node scripts/check-vascular-coverage.mjs --write
npm run validate:atlas
npm run validate:supplemental
npm run validate:interactions
npm run check
npm run build
npx playwright test tests/vascular.spec.ts
```

血管登记和发布步骤可重复运行，会从 `vascularOriginal` 恢复旧网格后生成当前补丁，不会重复累加血管。发布后不应直接重建肌肉补丁：该操作已加保护，避免静默删除血管补丁；如需重建全部内容，应按上述顺序从基础模型开始。

`npm run validate:vascular` 接受明确披露的未完成项并检查本次完成范围的回归；`npm run validate:vascular -- --require-complete` 在当前版本应返回非零，防止把本版本误标为完整血管图谱。
