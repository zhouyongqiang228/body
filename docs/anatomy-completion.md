## 方法及检查范围

仅从固定版本Z-Anatomy的明确命名网格中提取顶点，排除分组标签、空网格和12三角形注释方盒。每个网格保留文件、源网格名、源ID、Git blob、SHA-256、固定提交、许可与配准记录。不会用源文件中的 `Spinal_cordj`、`Cervical_plexusj` 等标签方盒冒充脊髓或神经丛。

局部肌肉、筋膜及关节囊沿用已有骨骼配准区域的共享有界仿射变换。背阔肌用胸腰椎、髋骨、肩胛骨及肱骨近端参照拟合单一有界躯干仿射变换。长神经及新淋巴结、腺体共享同一个平滑位移场，由727个保留骨骼拟合参照点拟合薄板样条，平滑参数0.001。没有独立拖动每条神经的端点来强行连接。

- 新增几何未检出非退化三角形方向翻转；记录来源近退化三角形，不将其当作稳定的面积比例证据。
- 共享位移场参照点残差P95约2.27 mm，采样局部Jacobian行列式最低约0.578；这些是变换质量检查，不是神经或肌肉的解剖附着误差。
- 24组主要神经连接进行了来源及配准后最近顶点距离比较，其中22组不超过5 mm。左右臂丛后束到腋神经的来源距离原为约7.32 mm，配准后约7.50/7.45 mm，保留并披露该缺口，没有生成推测连接。
- 全部2,404个既有网格的ID、几何索引、包围盒、来源和配准记录保持不变，已有血管补丁继续保留。

## 重建与验证

在已有肌肉、关节和血管补丁之后运行。本补充包作为最后一层，可重复生成；不要先重建早期覆盖层而丢弃后续数据。

```sh
python3 scripts/fetch-supplemental-sources.py --completion --workers 4
python3 scripts/repair-anatomy-metadata.py
node scripts/prepare-completion.mjs
work/registration-env/bin/python scripts/register-completion.py
work/registration-env/bin/python scripts/check-neural-connections.py
node scripts/build-completion-atlas.mjs
npm run validate:completion
npm run validate:atlas
npm run validate:supplemental
npm run validate:vascular
npm run validate:interactions
npm run check
npm run build
npm run test:e2e
```

配准脚本使用既有 `docs/supplemental-registration.json` 及 `work/z-anatomy/bone-correspondences.json`。后者如不存在，可按肌肉与关节补丁说明运行 `node scripts/prepare-supplemental.mjs` 重新提取骨骼参照，无需重新发布旧覆盖层。Python依赖沿用 `scripts/registration-requirements.txt`。

`scripts/completion-parts.tsv` 为人工选定的来源名称和中文说明清单；新增和纠正后的说明分别保存在 `app/data/completion-descriptions.json` 与 `app/data/corrected-descriptions.json`。原说明重建器会读取这些覆盖表。
